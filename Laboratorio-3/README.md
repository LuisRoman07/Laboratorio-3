# 🌙 El Jardín de los Recuerdos

Un jardín digital encantado donde los recuerdos más
especiales se convierten en flores.

## Descripción

El Jardín de los Recuerdos es una aplicación web
interactiva que permite guardar momentos importantes
de la vida, clasificarlos por emociones y visualizarlos
como flores en un jardín mágico.

## Funcionalidades

- Crear recuerdos.
- Consultar recuerdos guardados.
- Editar recuerdos.
- Eliminar recuerdos.
- Buscar por título y descripción.
- Filtrar por emociones.
- Estadísticas del jardín.
- Persistencia de datos.

## Tecnologías

- HTML5
- CSS3
- TypeScript
- Vite
- SQL.js (SQLite)
- localStorage
- GitHub
- Vercel

## Base de datos

Se utiliza SQLite mediante SQL.js.
La base de datos se exporta y guarda en localStorage
para conservar los cambios entre sesiones.

## Instalación

1. Clonar el repositorio.
2. Ejecutar npm install.
3. Copiar sql-wasm.wasm y sql-wasm-browser.wasm desde
   node_modules/sql.js/dist hacia public/ (ya están incluidos
   en este proyecto).
4. Ejecutar npm run dev.

npm run build
